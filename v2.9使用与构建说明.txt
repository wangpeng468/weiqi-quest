围棋背谱闯关 v2.9.0 · 双人同屏对战版

【进入双人模式】
打开“对战练习”→“新一局”→模式选“●○ 双人对战”→选 9/13/19 路→“开始对战”。
切换模式会替换当前未结束的对局（有棋子时会二次确认），已完成的对战记录与闯关成绩不会删除。
同一台安卓平板两个人轮流点击棋盘，黑棋先走、白棋后走，不需要联网或电脑 AI。
仍可切换回原来的人机模式；三档难度和执黑执白只用于人机对战。

【落子和当局计分】
- 两方交替落子，按正规基本围棋规则提子、禁止自杀、禁止重复棋形。
- “悔棋”在双人模式只撤销最后一手；在人机模式沿用原来的悔棋方式。
- “看分数”显示当前盘面的黑白面积临时估算，不终止本局。白棋另加 7.5 目贴目。
  提前数目可能不准，盘上尚未围住的空地不能当作最终地盘；也没有自动确认所有死棋。
- “判胜负”按本局当前局面自动结算，标注未确认死活和提早结束的估算警示，并保存记录。
- 双方连续点击“停一手”，同样自动算分并保存。
- 结束后可点“家长复核”，在棋盘上点击整块死棋标记 ×，再点“确认结果”，更新同一局成绩。
- 有争议时点“继续下”，将撤回该局已保存的胜负记录，继续落子后再结算。
- “认输”按当前轮到落子的一方认输，另一方获胜；会要求确认。
- 面积估算遵循活棋子 + 围住的空点，白贴 7.5。复杂死活、劫争、双活可能需要家长裁定，
  不能把本程序当作专业比赛裁判。

【双人对战记录】
打开“记录”→“●○ 双人对战”。页面显示黑棋获胜数、白棋获胜数、和棋数、估算局数；
可以按“全部 / 黑棋胜 / 白棋胜 / 估算”筛选，并点击某条记录查看当局的胜负和点数。
“⚔ 人机对战”只显示与电脑对局的胜负及人机胜率。双人模式没有个人胜率。
每种模式分别最多保留最近 100 局已结束的结果；未结束的局只保存在“当前对局”。
所有数据仍保存在原来的本机 progress JSON 中；导出的 JSON 备份可合并恢复，旧 v2.8 人机记录也能识别。
卸载/清除应用数据可能删除本机记录；建议在升级前通过“备份记录”导出 JSON 到平板之外。

【构建和覆盖升级】
源码版本 2.9.0（Android versionCode 20900），包名仍是 org.weiqi.memory。安卓原生层和离线资源格式未改变。
修改前端源文件在 web-src/；运行 npm install && npm run web 后，生成 assets/ 中的兼容 WebView 的 ES5 文件。
测试：node test_battle_rules.cjs && node test_auto_scoring.cjs && node test_two_player.cjs
GitHub Actions 会自动执行这些检查并尝试构建 APK。
已经安装的旧版必须由原来的 PEM 私钥/DER 证书签名才能覆盖安装；仓库不保存原私钥。
在 GitHub Secrets 没配齐原始签名材料前，APK 工作流会安全失败。绝不能自行换密钥假装覆盖升级。
可按 docs/GITHUB_APK_SIGNING.md 配置。未做所有安卓平板型号的真实设备升级验证。
