围棋背谱闯关 · v2.7.0 离线对战与标题朗读版

直接安装 APK 即可，不需要本源码包。安装前先在旧版导出 JSON 备份，保留旧应用，覆盖安装，不要先卸载。包名、证书、SharedPreferences 名和 WebView origin 均沿用 v2.6.1。

新增功能
1. 右侧关卡标题区域（含副标题）可以点击朗读，标题后有小喇叭图标。548 个内置关卡名称全部有预置录音。朗读遵循右上角语音开关；关闭时不会发声。自导入标题没有预置录音时使用“打开棋谱”通用提示。
2. 右侧导航增加“对战”。默认 9 路、孩子执黑、轻松难度；新一局可选 9 / 13 / 19 路和执黑/白。
3. 轻松、认真、挑战三档可以在对局中切换：分别使用随机化候选、单步战术评价、有界两层战术搜索。是本地启蒙陪练，不对应段级位，也不是 KataGo 或职业强度 AI。提示是参考点，不保证最优。
4. 悔棋退到孩子上次落子之前（包括电脑随后的一手）；思考中也可撤回。停一手、算分、认输、新对局有确认/设置步骤，取消不会清空棋盘。对局可暂停并在重新进入时继续。
5. 支持提子、禁止自杀和全局同形重复。双方连续停手后进入死子标记；点击整块棋切换标记，面积计算为活棋子加所围空点，白贴 7.5。不是自动死活裁判；复杂死活、双活等需家长检查，争议时可继续下。
6. 未完成对局与最近 100 局结果写入原来的 progress version=2 数据包，并由同一个原生备份机制保存。JSON 导出/恢复也包含对战。闯关与对战互不清空。
7. 最终对局可导出 SGF，再导入原有棋谱功能逐手查看。

声音和离线
新增 53 条中文提示，使用已选定的 Matcha B 音色、sid=0、speed=0.96；原有 495 个声音文件未改动。所有音频预先生成后打包，无现场 TTS、语音包、账号或联网需求。原有 548 关全部保留。APK 未申请任何权限，也未申请网络权限。

布局
保留横屏、左侧只有完整正方形棋盘、右侧所有按钮的布局。标题和菜单不会占棋盘上方。棋盘不滚动。设置/确认对话框允许必要的内容滚动。家长查看的备份和记录页可以在面板内滚动。

- 新对战交互、标题朗读、静音、悔棋与思考取消、认输/停手取消、死子标记、执白开局、对局恢复、JSON 备份合并均经过桌面 Chromium 测试。

构建
web-src 为源脚本；NODE_PATH=$(npm root -g) node transpile.cjs 生成 ES5 assets。使用 TypeScript。
使用实际 Android API 33+ android.jar 和 R8/D8 jar，设置 ANDROID_JAR / D8_JAR 后运行 bash build_native.sh。
本包不含签名私钥、语音模型、SDK、字体或开发机推理二进制。覆盖升级构建必须从你之前的私人开发备份恢复 private-signing；不要另造签名。
voice-tools 是配音生成参考；真正新增配音见 battle-voice-phrases.json / battle-voice-manifest.json，全部成品音频在 assets/audio。
