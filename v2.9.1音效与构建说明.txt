围棋背谱闯关 v2.9.1 · 离线音效版使用与构建说明

新增：右侧控制栏顶端，在原来的“🔊 语音开/关”旁边增加“🎵 音效开/关”按钮。
两个开关完全独立，可以只开语音、只开音效、两个都开或都关。
音效开关状态保存在设备本机（localStorage），重启仍保留选择；默认开启。
语音仍使用原内置中文 MP3，不会因音效开关受到影响。反之关闭语音也不会关闭音效。

音效清单（全部由 Web Audio 在本机实时合成，不访问网络，也无需额外音频文件或权限）：
- 人机/双人落子：轻微棋子敲棋盘声；提子：两下轻敲。
- 停一手、悔棋：短而柔和的不同提示声。
- 错误落子：低音提醒；打谱正确：轻微肯定音；看提示：轻提示音。
- 闯关完成或对局正式结算：简短三音提示；家长标记死子：轻点声。
- 重新打开音效：短试听音；关闭音效后所有效果立即静音。
默认音量经过限制，不增加连续背景音乐，避免长时间学习时的干扰。
Web Audio 需要设备 Android WebView 支持；不支持时安全静音，不影响正常落子和记录。
Android WebView 通常要求触摸操作后才允许播放音效；首次落子/点击可解锁。

界面与进度：
- 语音与音效按钮仅在右侧控制区域，棋盘左侧不增加控件。
- 沿用横屏布局，全部 548 关、离线语音、人机/双人对战、自动计分和历史记录。
- 记录字段、包名 org.weiqi.memory 和进度存储格式保持兼容。
- 版本 2.9.1 / Android versionCode 20901。
- 修改源文件：web-src/sfx.js、web-src/app.js、web-src/battle.js 和 web-src/voice.js；运行 npm install && npm run web 生成 assets/*.js。
- 校验：node test_sfx.cjs && node test_two_player.cjs && node test_battle_rules.cjs && node test_auto_scoring.cjs。

已安装旧版 APP 必须使用相同原私钥签名才能覆盖升级并保留应用记录。
仓库始终不包含原始签名私钥；仓库 Secrets 未配置之前，普通正式签名构建会安全停止。
建议升级前在“备份记录”导出 JSON；不要卸载旧版或清理应用数据。
尚未在用户平板上进行声音音量/真机实际播放验证。
